# DigiLab - Digital Services Agency

A modern, responsive website for a digital services agency built with HTML, CSS, and JavaScript.

## 🌐 Demo

Visit the live site: [DigiLab](https://digilab-ten.vercel.app/)

## ✨ Features

- Responsive design
- Animated sections using AOS library
- Dynamic carousel using Owl Carousel
- Sticky navigation
- Service showcase
- Project portfolio
- Client testimonials
- Contact form
- Social media integration

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery
- Font Awesome
- AOS (Animate On Scroll)
- Owl Carousel
